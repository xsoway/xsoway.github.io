在这个信息爆炸的时代，我们每天被算法推荐的碎片化内容淹没，却往往错过了真正关心的行业动态。

今天要介绍的这款开源神器 **TrendRadar**，就像它的名字一样，是一个“趋势雷达”。它能帮你聚合全网热点，通过智能筛选和推送，让你从“被动接受推荐”变成“主动获取信息”。

无论你是投资者、自媒体人，还是单纯关心时事的普通用户，这篇文章都能帮你搭建起属于自己的“热点监控系统”。

- --

## 核心亮点：它能为你做什么？

TrendRadar 不仅仅是一个简单的聚合工具，它更像是一个智能化的信息处理中心。它具备以下核心能力：

### 1. 全平台热点聚合

它默认监控 **11 个**主流平台，包括：

- **社交与资讯**：微博、知乎、抖音、Bilibili、百度热搜、今日头条、澎湃新闻、凤凰网、贴吧
    
- **财经与国际**：华尔街见闻、财联社
    

你也可以根据需求，自行增加额外的监控平台。

### 2. 智能推送与去重

面对海量信息，它提供了三种推送模式，解决不同痛点：

|模式|适用场景|推送特点|
|---|---|---|
|**当日汇总 (daily)**|企业管理者/普通用户|按时推送当日所有匹配新闻（包含重复）|
|**当前榜单 (current)**|自媒体人/内容创作者|按时推送当前榜单匹配新闻（持续在榜的每次都会出现）|
|**增量监控 (incremental)**|**投资者/交易员**|**仅推送新增内容，零重复**|

### 3. AI 智能加持 (v 6.5.0 新增)

告别枯燥的关键词配置，使用自然语言描述你的兴趣，让 AI 自动帮你分类新闻。

- **自然语言描述**：在配置文件中用日常语言写“我想看科技和股市”，无需学习复杂语法。
    
- **智能打分**：AI 对新闻进行批量分类打分，你可以设置最低分数阈值，只推送高相关度新闻。
    
- **自动回退**：AI 筛选失败时自动回退到关键词匹配，确保推送不中断。
    

### 4. 多渠道直达手机

支持将整理好的热点报告，直接推送到你的常用设备上：

- **群组工具**：企业微信、飞书、钉钉、Slack、Discord
    
- **个人设备**：Telegram、Bark (iOS)、ntfy (Android)、邮件
    
- **通用接口**：支持通用 Webhook，可对接 IFTTT 等自动化平台。

## 部署入门：如何拥有你的雷达？

搭建这个系统主要有两种方式，你可以根据自己的技术条件选择：

### 方案一：Docker 部署（推荐 ）

- **特点**：比 GitHub Actions 更稳定，数据本地存储，完全可控。
    
- **适用**：有自己的服务器、NAS 或长期运行的电脑。
    

### 方案二：GitHub Actions 部署

- **特点**：无服务器，利用 GitHub 免费资源，但需配置云存储以获得完整体验。
    
- **适用**：没有服务器的用户，但需定期签到续期。

## 玩转推送：配置你的“消息秘书”

配置好部署环境后，最关键的一步是设置**推送渠道**。以下是几个热门渠道的配置要点：

### 企业微信（最简单）

适合快速配置，支持推送到企业微信群，或者通过应用推送到个人微信。

### 飞书机器人 (Feishu)

消息显示相对友好，适合团队协作。

- **注意**：若启用 AI 分析，飞书推送偶发会有数分钟延迟（推测为平台对 AI 生成内容的合规性审核）。
    

### Bark 与 ntfy（手机通知神器）

如果你只想在手机上收到简洁的弹窗通知：

- **Bark**：iOS 专属，简单高效，支持自建服务器。
    
- **ntfy**：开源免费，支持 Android 和自托管。它提供了“免费版（够用）”和“自建版（完全隐私）”两种选择。
    

### 邮件推送

适合喜欢通过邮件阅读长文报告的用户。

- **注意**：邮件推送需要 HTML 报告文件支持，且为防止被滥用，收件人可能会看到彼此的地址。

## 开始你的第一步

如果你想尝试搭建这个系统，建议按照以下步骤操作：

1. **获取代码**：在 GitHub 上找到 TrendRadar 仓库，点击 "Use this template" 创建属于你的新仓库。
    
2. **配置 Secrets**：进入仓库的 `Settings` > `Secrets and variables` > `Actions`，根据你选择的推送方式（如飞书、钉钉、邮件等），添加对应的 Webhook URL 或 Token。
    
3. **调整配置**：通过可视化配置编辑器或直接修改 `config.yaml` 文件，设置你感兴趣的关键词（如“AI”、“新能源”、“股市”）和推送时间。
    

> **小贴士**：文档中提到，你还可以配置 **RSS 订阅源**，让 TrendRadar 像抓取热榜一样抓取你指定的博客或网站内容，实现个性化的信息聚合。
