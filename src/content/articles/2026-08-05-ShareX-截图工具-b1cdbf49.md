Windows 上截图这件事，每个人都在用，但很少有人觉得"够用了"。

微信截图要开微信，QQ 截图要开 QQ，系统自带的 Snipping Tool 功能太基础，Snipaste 好在贴图但上传和录屏是短板。每次录个演示要换一个工具，截完图要手动传到图床，OCR 又要开另一个软件——截个图而已，硬生生搞成了多工具协同作战。

ShareX 在这个位置上已经待了十几年了。它不是"又一个截图工具"，它是把截图、录屏、GIF 录制、图片编辑、OCR、文件上传、颜色取色、尺子、二维码、哈希校验……全都塞进一个免费开源软件的 Windows 桌面工具。

**ShareX 是一个免费开源的 Windows 截图、录屏、文件分享和生产力工具。截图只是起点，它真正做的事是：截完图之后，自动执行你配置好的后续流程。**

**核心亮点**

**1. 截图方式多到用不完**
全屏、活动窗口、活动显示器、区域截图、滚动截图、上次区域、自定义区域、屏幕录制、GIF 录制、自动截图……光截图方式就列了 10 种。滚动截图在抓网页长图或文档时特别实用，不用拼图。

**2. 截完图之后能干的事比截图本身还多**
截完图后，ShareX 可以自动执行：复制到剪贴板、保存到文件、打开图片编辑器、上传到图床、打印、在资源管理器中显示、运行自定义动作、扫描二维码、OCR 识别文字。这些"截图后任务"是 ShareX 的核心——它不是一个截图工具，是一个截图工作流引擎。

**3. 内置图片编辑器，标注/打码/特效一条龙**
截图后可以直接编辑：画矩形、椭圆、箭头、文字、对话气泡、步骤序号、高亮、模糊、马赛克、放大镜、聚光灯。敏感信息用模糊或马赛克遮掉再分享，不用切到 PS 或别的工具。编辑器还支持裁剪、抠图、背景替换、图片效果。

**4. 上传目的地覆盖全面，支持自定义**
图片、文字、文件、文件夹、剪贴板内容、URL 都可以上传。内置支持大量图床和云存储，高级用户可以创建自定义上传器，官方还提供了 Amazon S3、Google Cloud Storage、Cloudflare R2 的配置指南。适合个人分享，也适合团队统一存储。

**5. 内置实用工具，不止截图**
颜色取色器、屏幕取色、屏幕尺子、图钉到屏幕、图片美化、图片效果、图片查看器、背景移除、图片对比、图片拼接、图片分割、图片缩略图、视频转换、视频缩略图、图片分析、OCR、二维码、哈希校验、元数据查看器、目录索引器、剪贴板查看器、无边框窗口、窗口检查器、显示器测试。总共 20 多个实用工具，很多是日常高频使用的。

**6. 工作流可配置，热键驱动**
ShareX 的核心是"可配置的工作流"。给每个截图方式绑定热键，设定截图后做什么、上传后做什么。可以做到：按热键截区域 → 自动打开编辑器标注 → 保存到本地 → 上传到图床 → 缩短 URL → 复制链接到剪贴板。全程一次热键触发。

**7. 免费开源，无广告，无需账号**
这是最硬的一个优点。完全免费，代码开源，没有广告弹窗，不需要注册账号。对于注重隐私的用户来说，ShareX 的隐私政策也明确说明了数据收集范围。

**8. 多安装渠道**
官网、GitHub Releases、Microsoft Store、Steam 都能装。还有便携版，解压即用，不写注册表。开发版也公开，想尝鲜可以随时追最新改动。

**9. 社区活跃，生态成熟**
GitHub 上星数很高，有 Discord、Reddit 社区，官方文档涵盖 OCR、自定义上传器、命令行参数、翻译等各个方面。还维护了一个 ShareX 相关项目列表，插件和扩展生态成熟。

**快速上手**

从官网下载安装：https://getsharex.com/downloads

安装后，ShareX 会在系统托盘运行。默认已经配置了一些常用热键：

- **截取区域**：`Shift + Print Screen`
- **截取全屏**：`Print Screen`
- **截取活动窗口**：`Alt + Print Screen`
- **屏幕录制**：`Ctrl + Shift + Print Screen`

按热键截图后，默认会打开图片编辑器，编辑完成后可以选择保存、复制或上传。

刚上手时可以打开**设置 → 热键**，查看所有默认热键；打开**设置 → 截图后任务**，配置截图后自动执行的操作。

**写在最后**

ShareX 不是那种"看起来很酷但用不上"的项目。它解决的是真实问题：Windows 上没有一个免费的、集截图/编辑/上传/录屏/OCR 于一体的工具，用户不得不在多个工具之间来回切换。ShareX 把这件事做完了，而且做了十几年还在持续更新。

几个值得注意的点：Windows only，Mac 和 Linux 用户用不了。功能多意味着设置项也多，初次上手可能需要花点时间配置热键和后置任务，但一旦配置好，日常使用几乎可以完全脱离鼠标。另外，上传功能依赖网络，如果你在内网环境使用，需要确认上传目的地是否能连通。

项目完全开源，C# 编写，GitHub 上代码可读性不错，想自己加功能或者修 bug 门槛不高。官网文档很全，从基础使用到自定义上传器都有教程。
