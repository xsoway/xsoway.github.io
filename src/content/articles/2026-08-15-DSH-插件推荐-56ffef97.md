# DeepSeek Harness 插件生态：377 个插件，我挑了几个最值得装的

> 一句话结论：**dsh 的插件生态已经 377 个了，而且拧螺丝的、养宠物的、做番茄钟的、画 DAG 的什么都有，我挑了一圈，把你最可能需要的列出来了。**


写完了那篇 dsh 开箱指南之后，我就一直在琢磨一个问题——如果说 dsh 就像一台原生支持"一切皆插件"的精神内核的机器，那它到底能装什么？

当时写那篇文章的时候，提到了 dsh 底层是 Cordis 插件框架，模型适配器是插件，工具注册表是插件，会话日志是插件，Agent Loop 本身也是插件。但那时候我其实没真正去翻过插件列表，属于"理论对了但实践还没跟上"。

然后搜到了 awesome-dsh-plugin 这个仓库。打开一看，直接给我整不会了。

**377 个插件。**

而且不是那种"论如何写出一个 Hello World 插件"的示例集合，是真正有人在使用、有人在维护的东西。什么输入框里 @ 文件引用、侧边栏里挂终端、对话里渲染交互式 UI、甚至还有人在输入框上面加苹果用量统计条。

我寻思了一下，这尼玛有点离谱了。

于是我把这 377 个插件翻了一遍，按用途分类，挑出那些我觉得真正实用的、或者单纯很有趣的，整理成这份指南。

坦率的讲，这篇文章不是教你"怎么写插件"——那是上一篇文章干的事。这篇文章是**给你一份插件购物清单**，让你知道现在 dsh 生态里有什么好东西，哪些值得装，哪些可以当玩具。

---

先回答一个最基础的问题：**怎么装插件？**

很简单，一行命令：

```bash
dsh plugin --profile web add <插件名>
```

或者如果你装了 **dsh-market**（推荐），直接在 Web UI 里点几下就行：

```bash
dsh plugin --profile web add dshmarket
```

装完之后，这个插件市场就挂在你的设置面板里，搜索、安装、升级、卸载，全 GUI 操作，跟手机 App Store 一样。

如果连装插件市场都觉得麻烦，还有个更骚的——装 **dsh-find-plugin**，直接跟你的 Agent 说"我要能 @ 文件的插件"，它自己帮你搜：

```bash
dsh plugin --profile web add dsh-find-plugin
```

好，废话不多说，直接上清单。

## 一、先装插件管理器

如果你只装一个插件，装它。

**dsh-plugin-hub** —— 已安装插件一键启用/停用，内置 GitHub 插件市场，支持详情查看与一键安装。

装完它之后，所有后续插件的安装和卸载都可以在 Web 界面里完成，不用再敲命令行。这属于插件基础设施，就像你买了新手机第一件事是装个应用商店一样。

## 二、UI 增强类——装了就不想回去

### 2.1 上下文洞察插件

**dsh-context** —— 这个插件给 Web UI 加了一个上下文洞察面板。一眼就能看到模型上下文窗口的组成——总大小、已用多少、按请求时间趋势、压缩/注入事件、消息级 token 统计。

啥意思呢？就是你的 Agent 在干活的时候，你不再是一个"黑洞观察者"。你可以看到它的上下文窗口里到底塞了什么东西，每次对话占了多少 token，哪一步开始膨胀了。

这玩意对重度用户来说太重要了。用 dsh 写代码的时候，经常写着写着就忘了前面说了什么，Agent 也容易断片。有了这个面板，你可以在 token 快爆炸的时候及时止损，开一个新会话。

### 2.2 侧边栏工作台

**DSH-better-sidebar** —— 侧边栏完整工作台：内置文件渲染编辑、终端、Git 与子代理，支持三方插件注册新 Tab。

这个插件相当于在 dsh 的右边挂了一个 IDE。你要看文件不用切出去，要跑 Git 命令不用开终端，要预览 Markdown 渲染结果直接在侧边栏看。

而且它支持第三方插件注册新的 Tab。也就是说，后面有人写了一个"侧边栏代码审查"插件，它可以以 Tab 的形式直接挂进去。

搭配它的扩展插件更好用：

- **dsh-workspace-search** —— VS Code 式工作区关键词搜索（同时匹配文件名与文件内容，结果按文件分组带行号）
- **dsh-media-preview** —— 音视频预览器，内置流式媒体路由

### 2.3 对话节点导航

**dsh-navbar** —— 右缘节点串快速跳转。对话长了之后，想回到"15 分钟前那个关键问题"简直是灾难，得手动翻半天。这个插件在右边给你挂了一串节点，点一下直接跳。

类似的还有 **dsh-message-preview**、**dsh-chat-timeline**、**dsh-milestone**、**dsh-turn-navigator**、**dsh-outline**，都是干类似的事，但实现方式不一样。

我个人推荐 **dsh-outline**——它不只是按对话轮次跳，还按 Markdown 标题层级生成大纲树，流式生成时实时更新，点击节点滚动定位并高亮。这更适合写长代码、做长文档的场景。

### 2.4 用量统计 —— 知道自己花了多少钱

跟 DeepSeek API 打交道的，一定关心花了多少钱。这里有一堆：

- **dsh-usage-stats** —— GitHub 风格用量热力图，按工作区统计使用次数与 Token 花费，含缓存命中率
- **dsh-cost-balance** —— 输入框下方的 iOS 风格统计条，一键展开看会话花费、余额、缓存命中率
- **dsh-spend** —— 右下角悬浮窗，按模型/按天/按会话多维聚合
- **dsh-balance-plugin** —— 侧边栏 DeepSeek 余额与 Token 用量监控
- **dsh-usage-chart** —— 输入框下方仪表盘，零依赖 SVG 图表

这么多选择怎么选？我的建议是：**选一个就行**。功能大同小异，纯粹看你喜欢放哪。

我自己的选择是 **dsh-cost-balance**，因为它放在输入框下面，不占侧边栏空间，而且 iOS 风格那个统计条确实好看。

### 2.5 文件引用与拖拽

**dsh-at-file** —— Codex 风格的 @file 文件引用。在输入框里输入 @，就能搜索并引用工作区文件。

还有 **dsh-drag-and-drop** 和 **dsh-drop-file-to-path**，都是拖拽文件到输入框，自动以蓝色 chip 插入路径。区别在于前者是跨平台通用，后者是存到 ~/.dsh-dropbox 隔离存储。

**dsh-input-plus** 更进一步——在组合框里用 @ 搜索工作区文件和目录路径，还支持 /h 菜单复用当前会话的问题。

### 2.6 生成式 UI

**dsh-genui** 和 **dsh-visualize** 这两个值得单独说。

装之前，Agent 回给你的东西只有文字。装之后，Agent 可以**在对话里渲染交互式 UI 组件**——布局、图表、表单、测验、Mermaid 图、3D 场景。

什么意思呢？就是你说"帮我画一个项目进度甘特图"，Agent 不是写一段 Markdown 给你，而是直接在会话流里渲染出一个可交互的甘特图。你可以在上面拖拽、点击、查看详情。

这体验太爽了。第二个插件黑长直的动作没第一个插件大，但 dsh-annotation 可以让你选中文字 → 批注 → 随消息发送，回复按批注逐条对照。适合做代码 review 和文档审校。

## 三、主题与外观类——手机也能用

### 3.1 移动端适配

这可能是被低估最狠的一个需求。

dsh 的 Web UI 默认在窄屏下体验一般，侧边栏占太多空间，设置面板也叠得乱七八糟。但如果你跟我一样，经常在手机上远程看 Agent 跑了什么，这俩插件是刚需：

- **dsh-web-mobile-fix** —— 窄屏下设置面板全屏化、插件导航单行排满、侧边栏全屏、弹层居中、会话日志按钮图标化
- **dsh-web-mobile** —— 窄屏下侧边栏变为 overlay 抽屉、会话独占全宽、设置面板改为近全宽 sheet

两个二选一就行，我倾向于 **dsh-web-mobile**，抽屉式菜单更符合移动端直觉。

### 3.2 局域网访问

**dsh-web-lan-access** —— 给非 HTTPS 的局域网访问注入 crypto.randomUUID polyfill，Tailscale IP 直连时前端不再崩溃。如果你用 Tailscale 远程访问 dsh，这个插件必须装，否则浏览器会报错。

**dsh-mobile-gate** 更进一步——子进程反向代理 + 首次访问审批 + 设备令牌绑定 + 限流 + 手机端紧凑排版注入。这更适合多人团队共享 dsh 的场景。

### 3.3 皮肤与动画

dsh 的皮肤生态已经相当丰富了：

- **dsh-skin** —— Codex 风格皮肤切换器，支持自定义壁纸层，可调透明度与模糊
- **dsh-deep-whale** —— 鲸鱼娘皮肤系列（深海女仆工坊），看着就可爱
- **theme-gallery** —— 15 个精选主题家族，浅深配色完整
- **dsh-client-ui-skin-claude** —— Claude 风格皮肤：暖黑画布、陶橙点缀、衬线 UI

还有一堆状态动画插件：**dsh-whale-animation**（持久化黑色鲸鱼深潜动画）、**dsh-status-rotator**（把"Deep diving..."换成自定义文案，按阶段轮换，打字机与流动渐变效果）、**ui-status-label**（自定义状态文案）。

说真的，dsh 的皮肤生态已经比很多商业软件丰富了。我目前用的是 **dsh-deep-whale** + 一个浅色主题的混搭。

## 四、会话与消息类——提升对话效率

### 4.1 自动续跑

**dsh-auto-continue** —— 这个插件我愿称之为"救心丸"。

dsh 有时候跑长任务会断——网络波动、超时、宿主崩溃。以前你只能手动点"继续"，然后祈祷它没失忆。这个插件能自动检测失败类型，自动发送"继续"，支持错误分类、自适应退避、模板化继续文本与浏览器通知。

装了之后，你可以放心让 Agent 跑一个 20 分钟的长任务，不用盯着屏幕。它自己会续。

### 4.2 番茄钟

**dsh-pomodoro** —— 谁说 Agent 开发者不需要番茄钟？可配置专注/休息循环、可拖动迷你面板，站内提醒、提示音和浏览器通知。

我写代码的时候经常"沉浸式"到忘记时间，这个插件帮我解决了这个问题。而且它会停在界面上，不会像手机上番茄钟那样被通知栏吞掉。

### 4.3 语音输入

**dsh-mic-input** —— 浏览器 Web Speech API 实时转写，自动去重/续听、智能标点，支持语言与自动发送设置。

如果你用 dsh 做头脑风暴或者快速记录，打字是瓶颈。这个插件让你可以直接说话，Agent 会自动把你的语音转成文字发出去。实测中文识别准确率还可以。

### 4.4 便签与大纲

**dsh-sticky-note** —— 编辑框工具栏便签，随手记点子和 TODO，自动保存为 Markdown，一键发送到对话。

**dsh-chat-outline** —— 对话栏左侧常驻大纲，按轮次列出提问与最后回复，支持关键词过滤与一键跳转。

## 五、记忆与工作流类

### 5.1 任务 DAG

**dsh-task-dag** —— 这个是让我觉得"dsh 的插件深度已经超过好多商业软件了"的插件。

它会将会话子代理与持久工作流运行展示为**实时 DAG**。你能看到每个子任务的状态、依赖关系、执行顺序，Agent 重启后历史也能恢复。

如果你在写复杂的多步骤 Agent 任务，这个插件能让你从"黑盒观察者"变成"白盒调度者"。

### 5.2 提示词增强

**dsh-prompt-enhancer** —— 一键把模糊草稿改写成更强提示词，不满意可撤回。内嵌独立 LLM 调用，不消耗你当前会话的上下文。

### 5.3 深链直达

**dsh-deeplink** —— 支持用 ?session= / ?workspace= 参数直接打开指定项目对话。适合做浏览器书签，或者把某个对话链接分享给团队。

## 六、开发与运行时类

### 6.1 底部终端

**dsh-plugin-terminal** —— 底部多标签终端面板（node-pty + xterm.js），贴底全宽，输入框始终在终端上方。

这个插件的交互很聪明——它不占侧边栏空间，而是贴在底部，跟浏览器的 DevTools 终端一个画风。输入框在终端的上面，所以你不会"发到终端"还是"发到对话"搞混。

### 6.2 设计预览

**dsh-openpencil** —— OpenPencil 设计预览与编辑插件。如果你在 dsh 里做 UI 原型设计，这个插件可以直接预览你的设计稿，不用切出去。

### 6.3 代码 diff 查看器

**dsh-diff-viewer** —— PiUI 风格 diff 查看器，替换 write/edit 工具调用的默认 DiffBlock。

默认的 diff 显示比较朴素，这个插件把它升级成了 PiUI 风格，改行、增行、删行一目了然。

### 6.4 自动收卷

**dsh-sticky-disclosure** —— 一键收起会话中所有展开的区块（Think、工具卡等），常驻计数按钮 + 自定义快捷键。对话长了之后，手工一个个收展开的 Think 块太痛苦了。

## 七、桌面宠物类——纯粹的快乐

这一节跟效率无关，纯粹是"为什么不做呢"。

**dsh-answer-pet** —— 蓝鲸桌面宠物，按会话实时展示回答进度、模型动作与工具调用轨迹、token、输出速率与耗时，支持多会话状态卡片展开收起。

**dsh-pet** —— 精灵图动画、agent 状态联动、拖拽、闹钟（每天/一次）与番茄钟，皮肤下拉选择 + 预览。

**dsh-desktop-pet** —— 完全支持 Codex 桌宠格式，可用 hatch-pet Skill 创建自定义宠物，或通过 Petdex 导入。

我装了 **dsh-answer-pet**，因为蓝鲸形象跟 dsh 的"Deep diving"梗太契合了。看着那只蓝鲸在 Agent 思考的时候深潜下去，token 在飙的时候它潜得更深，输出结果的时候冒泡浮上来——这体验很难用语言描述，但你用了就知道。

## 八、Windows 原生壳

如果你在 Windows 上跑 dsh，或者有 Windows 远程桌面，这俩插件可以关注一下：

- **dsh-desktop-windowos** —— Windows 托盘桌面壳，自动从 GitHub Releases 安装 exe、创建桌面快捷方式，提供 desktop_launch 工具在对话中一键启动
- **dsh-window**（ZichengGurrr）—— WebView2 原生窗口，功能类似

## 十、一些思考

377 个插件，这个数字本身已经说明了一些事。

dsh 的插件生态能这么活跃，我觉得核心原因在于它的**插件开发门槛足够低**。所有插件都是 TypeScript，写一个 Hello World 插件可能花不了 10 分钟。而且 dsh 的插件不是"插在某个预留接口上"的，是**可以替换任何内部组件**的——包括模型适配器、Agent Loop、甚至会话存储引擎。

但反过来，这也带来一个问题：**插件太多了，选择困难。** 377 个插件，其中很多功能重叠，用户不知道怎么选。这也是我写这篇文章的初衷——帮你快速缩小范围。

我对 dsh 插件生态的期待，其实不是"插件数量能不能破千"，而是**能不能出现一个像 VS Code 的 Marketplace 那样真正有筛选机制的生态**——评分、下载量、安全审核、依赖树。dsh-market 已经在做这件事，但毕竟才起步。

不过话说回来，一个开源 Agent 框架，上架 377 个插件，其中不乏让人"卧槽还能这样"的骚操作——这本身已经是一份很漂亮的成绩单了。
