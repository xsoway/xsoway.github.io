# 发内容最烦的不是写不动，是写之前根本不知道做什么

做过自媒体、公众号或者小红书的人，多半都撞过这堵墙：选题靠"感觉"，标题靠"我觉得会爆"，配图排版磨半天，结果发出去石沉大海。你跟 AI 说"帮我想 10 个选题"，它倒是张口就来，可那些选题你闭着眼都觉得是套话——它们根本不来自你的平台、你的赛道、你的用户。

说白了，你缺的不是"会写"，是**动手之前那一步"到底什么在传播"的情报**。

最近 GitHub 上有一整套专门治这个的——**Creator Buddy**。一句话：**它不是让你凭感觉编选题，而是先把平台上的真实内容和数据拉回来，再手把手帮你做成能发的东西。** 它把"从一个选题，到一篇能发的成品"整条路都给你铺好了。

---

## 1. 这是啥：一套给三平台创作者用的创作工具箱

先把它是什么钉死：**它是一套给内容创作者、运营和自媒体用的全栈创作 Skill 工具箱，覆盖公众号、小红书、视频三个平台的创作全流程。** 从翻热点、挖爆款、看评论、拆竞品这类的"情报"，到起标题、写正文、做配图、剪视频、配音配乐、出封面这类的"成品"，它都管。

它不是"一键起号"那种玄学，也不替你把内容卖给谁——它有一条硬原则：**内容永远是你的。** 它只负责把环境和原料给你拉回来、帮你一步步做成能发的东西，最后落笔的、发布权的都在你自己手上。

## 2. 仓库塞了些什么：一眼就是一个完整的创作台

打开仓库，它按平台分三大块，每块里又是一个一个独立的 Skill，各管一段活：

| 板块 | 管的是哪一段 |
|---|---|
| `gzh-Skills/` | 公众号：定位装修 · 搜爆款 · 长短文 · 起标题 · 做封面 · 配图 · 排版 |
| `xhs-Skills/` | 小红书：起号定位 · 选题 · 标题 · 正文 · 封面 · 图文 · 复盘 |
| `video-Skills/` | 视频：选题 · 脚本 · 剪辑 · B-roll · 字幕 · 配音配乐 · 封面 |

每个子目录都是一个独立 Skill（一份 `SKILL.md` + 可选脚本和 references）。它覆盖的不只是"我能生产东西"，而是更大野心：**从你账号的定位，到一篇发出，全都包圆了。** 你别小看这点——这恰恰是"工具箱"和"一个写稿脚本"最大的差别。

下面我用小红书那 10 个环节当例子，你就清楚它"全流程"到哪个程度了：

| Skill | 它帮你搞定什么 |
|---|---|
| `space-xhs-buddy` | 总控：判断你卡在哪一环，再路由并串起工作流 |
| `space-xhs-positioning` | 起号：赛道、定位句、人设、内容支柱、冷启动 |
| `space-xhs-hotspot` | 热点选题：拉高互动笔记、判趋势、爆款共性 |
| `space-xhs-title` | 爆款标题：15 种方法批量出候选、评分、合规 |
| `space-xhs-writer` | 笔记正文：7 种类型、标签策略、发布前 14 项体检 |
| `space-xhs-cover` | 封面：Codex 内置生图，3:4，单张或多版测试 |
| `xhs-html` | 图文排版：6+ 张 3:4 单文件 HTML，62 种风格 |
| `space-xhs-image` | AI 信息图：Codex 生图，单图或 6–9 张组图 |
| `space-xhs-account-audit` | 账号体检：八维打分、竞品对标、卡点定位 |
| `space-xhs-note-analytics` | 笔记复盘：六层漏斗归因、横向找规律 |

公众号、视频两块也是这个量级。这么一看就懂它有多大：不是一条套路，而是一整套按平台、按环节分门别类的创作工具箱。

## 3. 它比"帮我想 10 个标题"强在哪——先还原平台语境

写套话类 AI 描述太容易：你让它"帮我想 10 个选题"，它给你吐一堆纸面上的套话。Creator Buddy 的差异在多走了一步**情报**：先去把平台上的真实内容、真实互动拉回来，再基于这些出结论。

看它这个"先做情报"的示例，你瞬间就懂那种"有数据做底"和"空口说"的差别：

```text
用户  ❯ 帮我看看最近 Codex 在小红书上有什么爆款

助手  ❯ 已搜索小红书热门笔记，近 7 天 39 条筛出 10 条高相关：
        1. 低成本玩转 Claude Code：6w+ 互动
        2. Codex 写文献综述：1w+ 互动
        3. 5 分钟安装 Codex：1w+ 互动
        结论：小红书用户不关心「模型多强」，更关心怎么装、怎么省钱、
        怎么避坑、普通人能不能用、能不能马上做 PPT/论文/剪视频。
```

你看到的是"选题方向是从数据里长出来的"，而不是"AI 的脑补"。它连"怎么装、怎么避坑、能不能用"这种用户真实痛点都给你拎出来了——这比你拍脑袋要 10 个标题有用多了。

**再从情报做到成品**——它不只会"看"，还能往下做能发的东西：

```text
用户  ❯ 把这篇文章做成一支手绘图解 B-roll，垫在口播下面

助手  ❯ 已抽取原文 5 张配图 → 拆成 8 帧分镜（放射/流程/结论卡）
        → 逐帧生成手绘线稿静帧 → 调 Seedance 做「手绘生长」动效
        → 硬切拼接 + 无人声氛围乐压低 → broll_final.mp4（4:3，48s）
```

一条"会呼吸"的 B-roll，它分步骤给你处理出来。市面上能画图的工具很多，能把你整套创作流程当一条流水线打通、还在中间每一步都有章法的，很难找。

这就是它的核心卖点，我画成一张流程图，方便你脑内过一遍：

```mermaid
flowchart LR
  A[翻平台内容情报] --> B[搜索爆款/评论/竞品]
  B --> C[去重评分排序出报告]
  C --> D[提炼选题方向]
  D --> E[做成标题正文配图]
  E --> F[视频字幕配音封面]
  F --> G[能发的成品]
```

## 4. 装它、用它们，其实就是一个命令的事

它基于开放的 Agent Skills 协议，只要你的 runtime（Claude Code、Codex、Cursor、OpenClaw、Hermes Agent 等都兼容）支持 skills，就能装。

**方式一，一行命令（推荐）：**

告诉你正在用的 agent：`帮我安装这个 skill：https://github.com/SpaceZephyr/creator-buddy`，或者直接用 CLI：

```bash
npx skills add SpaceZephyr/creator-buddy
```

它会自动识别当前 runtime 并放到对的位置；要指定时，加 `-a codex` / `-a claude-code` / `-a cursor`。

**方式二，手动安装：**

```bash
git clone https://github.com/SpaceZephyr/creator-buddy.git
```

然后按上面导航图把需要的 skill 目录复制到你的 skills 目录即可。

**方式三，当参考资料用：** 就算你的 runtime 不自动加载，直接打开对应目录的 `SKILL.md` 内容贴进对话也行。

装好后用大白话喊它就行，例如：

- "帮我搜一下小红书最近 Codex 的热门笔记"
- "查一下公众号里 AI Agent 相关爆款"
- "这篇文章帮我起 10 个爆款标题，标好方法和风险"
- "把这段内容做成公众号配图"
- "帮我把这条口播视频从头做到发：选题、脚本、剪辑、字幕、配乐、封面"

想手动跑脚本、拿公众号赛道分析报告，可以这样（`--days 7` 之类就是你想要的样本窗口）：

```bash
python3 gzh-Skills/baokuan-article-analysis/scripts/daily_sector_trends.py \
  --sector "AI Coding=Codex,Claude Code,AI编程" --days 7 --output-dir ./reports
```

## 5. 说点坦白话：强在这些，但边界也贴着给你看了

我是**认真读过整个工具箱结构、但还没在真实创作流水线上跑遍它全部 Skill**，下面一半按项目说明、一半是这类"创作工具"的通用规律说给你。

**顺手的点很眼馋**：最打动我的是它有那套明明白白写出来的"诚实边界"——它明确写"一个不告诉你边界在哪的创作工具，不值得信任"。它不是那种只会报好话、把啥都夸上天的软文型工具，而是一上来就告诉你它有哪些做不到。这在一个吹牛的行业里，算是根清流。

**同时它有门槛**：它默认"只读公开数据"，不做发帖、点赞、收藏这些写操作，也不承诺绕过任何验证码和风控。这既是安全边界，也等于告诉你——**它是个"研究+产出"工具，不是"自动运营"机器。** 你别指望它替你天天发帖涨粉丝，它管的是创作和决策那半边。

**还有几点你动手前最好有数**：

- **平台数据是"公开页/第三方"，不是实时后台。** 它读的是公开页面、公开 API、只读 CLI，所以可能不是平台后端的实时数，是"公开语境"的还原。
- **热门 ≠ 适合你。** 爆款只说明"平台上什么在传播"，它替代不了你的定位判断——这恰恰是通过写作帮你，而不是替你判断那句话。
- **小红书受 `xsec_token` 影响**、抖音那块是"扩展入口"，得你自己接本地只读 CLI 才有。
- **AI 出的配图/视频可能有错别字或瑕疵**，交付前得人工检查一遍。

**一句话判断**：**它是"真做内容"的人的强辅助**——适合要系统做公众号/小红书/视频、想靠真实平台数据而非感觉来选题的你。**不适合**想"把号丢给它、一键运营涨粉"的懒人——它给不了你那神奇的一键。
