# 别让 AI 跟你绕圈子了：它不认得你，但这个技能让它开口就是"下一步干这个"

你有没有被 AI 的回答气到过——先夸你一句"问得好！"，再东拉西扯给你铺一脸背景，中间还得夹着几个"顺便一提""或许可以"，最后才恋恋不舍地来一句"希望这能帮到你！"收尾。

我等它说出正事的时间，已经够我把屏幕滚两回了。

我不是要它对我客气。我要的是"我下一步该敲哪行命令"。

所以见着 i-have-adhd 这个仓库的时候，我心里就一个字：中。

---

## 1. 这到底是干嘛的

先把它钉死：**这不是给你诊断，也不是让你"变聪明"，而是一个 Claude Code 技能，专门治 AI 那套"话多而不落地"的毛病。**

它做的事一句话——**不是让 AI 更懂你，而是让 AI 更不会对你啰嗦。** 让输出"行动优先、步骤编号、不废话、总以具体下一步收尾"，把话痨式的回答，换成你拿到就能跑的命令。

适合谁用其实很宽：受够了 AI 长篇大论、只想让它说话"干净利落"的开发者都行。**它不为"确诊 ADHD"做准备，也不需要你做任何诊断**——只要你是那种嫌 AI 绕来绕去的人，它就对口。

好处是立竿见影的：你敲的每句话，AI 都顺着一条"先说下一步 → 编号 → 给个具体结尾"的规矩走，就像给 AI 装了个"不讲废话"的保险丝。

## 2. 里头长这样

这个仓库很轻，装的东西一眼就能看穿：

```text
i-have-adhd/
├── skills/
│   └── i-have-adhd/
│       └── SKILL.md        # 真正说了算的规则，十条就这么来的
├── .github/
│   └── readme/              # 多语言的说明书
├── logo.png                 # 项目 Logo
└── LICENSE                  # MIT
```

起决定作用的，其实是 `skills/i-have-adhd/SKILL.md` 那一个文件——十条规矩，全塞在里面。你要自定义，也是去改它。

## 3. 值在哪儿

真正的价值，不是它"能跑跑"，而是**它把 AI 的回答方式，从"写作文"拉回了"发指令"。** 我给你拆几条，你体会一下：

1. **先说下一步，不开场白。** 它能让你把"嗯，让我想想……"这种开场白直接省掉，上来就是"接下来做这个"。 → 省的是你反复追问"然后呢"的时间。
2. **多步骤用编号。** 中间两步三步，它不会绕来绕去，直接给你一列编号。 → 你照着顺序做就行，不怕卡在中间。
3. **每个具体结尾收束。** 结尾永远有一个"下一步"，而不是"你还有其他问题吗"。 → 你知道下一条该问它什么，没卡壳。
4. **时间估计用分钟，不说"一会儿"。** → 你心里有底，排期不乱。
5. **每轮都重述当前状态。** 哪怕是长任务，你也能随时知道"咱现在到哪了"。 → 中途去接杯水回来，也接得上咱们聊到哪了。

一句话：**它不是让 AI 变聪明，是让 AI 别装作聪明。** 聪明不难，难的是不抖机灵、直接干活——这才是它对口的地方。

## 4. 拉起就能跑

它是个给 Claude Code 装的技能，装好在会话里调一发就能用。仓库在"安装"那块给你放了一份专门的安装说明，先照着它走，再按最下面那个"自定义"片区把版本换成自己的。

一条提醒：**只有 fork 时用 CLI 的指令，才是官方文档里写死的。** 剩下"默认让它用上游"的路子，文档是丢给你看安装说明，我不编一条假命令填进去糊弄你。

想换成自己的副本，官方给的原样这几行（先卸上游，再换成你 fork 的那份）：

```bash
claude plugin uninstall i-have-adhd            # 先移除上游的副本
claude plugin marketplace remove i-have-adhd   # fork 与上游使用相同名称
claude plugin marketplace add <your-username>/i-have-adhd
claude plugin install i-have-adhd@i-have-adhd
```

跑完重启 Claude Code，再敲 `/i-have-adhd` 就是你的定制版了。要改哪条规矩，去改 `skills/i-have-adhd/SKILL.md` 那一个文件就行。

## 5. 装到别处也能用（多环境安装）

先说一句实话：**它是个 Claude Code 生态的 plugin，本来是为在 Claude Code 里跑设计的。** 你非要在别的 agent 里装，那是把它当"通用技巧"借用——不是我编出来的官方能力，是"组合着用的活"。所以下面我给你的是几条路子，你看哪个顺手：

**在 Claude Code 里（最直接）**

```text
用户  ❯ 帮我装一下 i-have-adhd 这个技能。

助手  ❯ 先卸上游再上你自己那份（不改的可以跳过）：
         claude plugin uninstall i-have-adhd
         claude plugin marketplace remove i-have-adhd
         claude plugin marketplace add <你的用户名>/i-have-adhd
         claude plugin install i-have-adhd@i-have-adhd
         装完重启，敲 /i-have-adhd 就能开启。想改规矩，去改
         skills/i-have-adhd/SKILL.md。
```

你只想在 Claude Code 里用默认版、不想 fork，那连上面都不用，直接照官方那份安装说明走就行——我不在这里给你编一句"一行安装"来糊弄你。

**在 DeepSeek Harness / 其他 agent 里（借用它那套产出习惯）**

其实就是把那十条"行动优先、步骤编号、时间给分钟、列表别超过 5 项"当成一句话 prompt 塞给 AI，效果也八九不离十。给你看个对话的样子：

```text
用户  ❯ 帮我把这份文档做成一个能直接执行的清单。

助手  ❯ 好，我按"先给下一步、再给编号步骤、结尾给具体下一步"来：
         1. 把规矩里"列表最多 5 项"那类，写成你要问时记得加。
         2. 每一步都给出能跑的指令。
         3. 结尾给出"你接下来该干嘛"，不带一句"希望这能帮到你"。
         这些都是我临时按它的风格套给你的，不是官方支持的接口——你自己要用，再把这几步当口诀记下就行。
```

**在 Python / PyCharm 里**

它本来也不是个 Python 库，所以这里没有 pip 那一套。你真正想要的，其实是"让我的 AI 助手别再长篇大论"，那直接把它那十条套进你的 prompt 就成。真要落地，我给一个思路（一样是套用，不是官方支持）：

```text
用户  ❯ 我用的不是 Claude Code，是 Codex 或别的 agent，能照搬吗？

助手  ❯ 能照搬的，是自己把这几条当成"系统提示"塞给你的工具：
         "先说下一步，多步用编号，结尾别问'还想了解吗'，时间给分钟，列表别超过5项"
         这些不是它官方能力，是把它那套"说到点子上、别拖沓"的习惯搬过来用。
```

所以要我说：**你要图省心，就装进 Claude Code 用原版；你要是想把这股"干净"劲儿借到别的工具里，就拿我上面那几条当心法自己试。**
