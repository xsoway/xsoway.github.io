# 中国独立开发者项目列表：7 天新增 50+ 项目，这个 GitHub 仓库还在更新

你想过一个问题吗——

国内独立开发者到底在做什么？做什么能赚钱？做什么能养活自己？

市面上关于独立开发的讨论，大多停留在"要不要出海""怎么选赛道""怎么搞定支付"这种通用方法论上。但你真正想看的，其实是具体的人做了什么具体的东西——有没有人把一个小工具做到月入过万？有没有人做了一款产品，虽然不是爆款，但就是有人愿意付费？

这个仓库就是干这个的。

**GitHub 上的 `chinese-independent-developer`**，一个持续更新的中国独立开发者项目聚合列表。不是方法论，是活人作品墙。

## 一句话结论

这是一个按"日期 + 开发者 + 一句话介绍"组织起来的项目目录，把中国独立开发者（含海外华人）做的网站、App、工具、游戏按时间线列出来，你想看最近有什么新东西上线，或者想找灵感、找对标、找能直接用的工具，翻它就够了。

## 核心亮点

### 1. 持续更新，不是"一次性归档"

这不是那种"2023 年整理"之后就没人管的静态列表。从 2018 年到现在，每周都有人在往里面加新项目。我拉到的近 7 天数据就新增了 50 多个项目，说明它的维护节奏是活的。

### 2. 按时间线组织，你能看到"最近有什么新东西"

仓库主 README 按日期倒序排列，最近一周的添加在最前面。这意味着你可以当作"独立开发者新作品周报"来刷，而不是翻一个几百项的静态清单。

### 3. 入选标准明确：只收"网站或 App"，不收开发者工具

这个筛选条件挺有意思的——它不要库、不要框架、不要 CLI 工具、不要论坛型网站。只收"普通用户打开就能用"的产品。所以你在里面找到的，都是面向终端用户的东西，而不是面向开发者的基础设施。

### 4. 产品介绍有规范，避免"一句话看不懂"

仓库维护者明确要求：不能写"AI 视频生成工具"这种抽象描述，必须写成"无需剪辑经验，3 步生成竖屏短视频"这种带场景的句式。这个细节提升了整个列表的可读性——你扫一眼就知道这个产品解决什么问题。

### 5. 三种状态标记：开发中、已上线、已关闭

每个项目前面有状态标记（🕐 / ✅ / ❌），你能一眼看出哪些是可用状态，哪些已经停更。这个设计很务实——一个列表的价值不在于它列了多少，而在于它告诉你哪些还能用。

### 6. 分主版面和子版面

主版面收的是"打开即用"的产品（网站和 App）。子版面另外有：

- **程序员版面**：需要命令行或写代码的工具
- **游戏版面**：独立游戏
- **2018~2020 年历史存档**

这样分类的好处是，你不会在主列表里看到一堆 CLI 工具和游戏混在一起。

### 7. 开发者来自全国各地（甚至海外）

列表里的开发者标注了城市：北京、上海、杭州、成都、昆明、乌鲁木齐、厦门、天津、海外……这说明独立开发这件事不是一线城市的专利，二线甚至更小城市的开发者也能做出不错的作品。

### 8. 产品类型非常丰富，覆盖了日常工具、AI、教育、娱乐

从"行测立体空间题练习小程序"到"AI 短剧生产平台"，从"离线中文输入法"到"演唱会座位视角图集"，从"家庭健康档案"到"可视化弹窗整蛊软件"——覆盖面很广，总有一类你会感兴趣。

### 9. 参与门槛低，PR 或 Issue 即可加入

如果你想把自己的项目加进去，直接发 Pull Request 或提 Issue 就行。不需要先成为什么大 V，也不需要你的项目有多少 Star。

## 2026 年 7 月最近一周，有哪些值得关注的项目？

我挑几个有代表性的，帮你快速过一遍（完整列表在仓库里，下面只是我感兴趣的）：

### AI 创作类

- **小野 AI**（开源）：多模态 AI 内容创作平台，支持 Gemini、Seedream、Veo 等模型生成图片和视频，还有电商图片批量生成功能
- **BigBanana AI 导演**：AI 短剧生产平台，从剧本到成片全自动化，号称"Script-to-Asset-to-Keyframe"工业化工作流，替代传统"抽卡式"生成
- **Agnes 视频生成器**：完全免费的 AI 视频生成工作流，网页版可直接体验，也有一键启动的 GUI 版

### 效率工具类

- **Nimclip**（macOS）：免费开源剪贴板历史工具，文本、链接、代码、图片、富文本都支持，数据只存本地
- **Moler**（macOS）：NASA-Punk 风格的磁盘清理工具，重复文件扫描、大文件检测、应用卸载一把抓
- **FocuSD Island**（Windows）：悬浮灵动岛效率工具，把待办、笔记、剪贴板历史、媒体控制放在屏幕顶部
- **Sillage**（iOS）：旅行记录 App，把足迹、火车、飞机、酒店放在一起，按时间轴回放

### 数据类

- **小米设备价格天梯**：覆盖 245 台设备的 Xiaomi/Redmi/POCO 价格与代号速查工具，纯静态页面，零依赖
- **SeatView**：日本及海外演唱会座位视角图集，在坐席图上点击就能看实拍视野
- **历史图轴**：把通史、断代史、历史人物、时间、地图联动起来的可视化工具

### 生活类

- **秒折立方**：微信小程序，行测/公考图形推理里的立体空间题练习工具，平面展开图点一下就折成正方体
- **薪跳 PayDance**：基于你的薪资和上下班时间，实时计算每一秒的收入增长
- **上海 City 不 City**：上海城市玩法发现站，AI 帮你规划约会、亲子、夜景等 City Walk

### 开发者向

- **WebCode**：基于浏览器的 AI 编程平台，支持远程运行 Claude Code 和 Codex 等 CLI 助手，随时随地写代码
- **Haven**：vibe coding 部署平台，上传 ZIP 或连接 GitHub，AI 帮你补齐支付、用户、日志、运维等环节，一天内交付可用产品
- **Agent Island**：Claude Code 与 Codex 的状态伴侣，实时显示会话状态，需要你接手时提醒

## 项目的结构

```
主 README（打开即用的网站/App）
├── 程序员版面（需要命令行或写代码的工具）
├── 游戏版面（独立游戏）
└── 2018~2020 年历史存档
```

主 README 里按日期倒序排列，每个条目格式：

```
开发者名 - [GitHub链接]
✅ [项目名](链接)：一句话介绍
```

## 适合谁翻这个列表

- **想找灵感**：看看别人在做什么，什么方向还有人做
- **想找对标**：你想做的方向，有没有人已经做了，做得怎么样
- **想找工具**：列表里很多产品是免费的，直接能用
- **想加自己的项目**：PR 或 Issue 提交即可

## 写在最后

这个仓库的价值不在于"收录了多少项目"，而在于它一直在更新，而且收录标准清晰、分类合理、信息密度高。

如果你对独立开发感兴趣，建议把它加个 Star，然后每隔一两周翻一次最近添加的页面。你不需要记住列表里的每一个项目，但你需要知道"最近有人在做什么"——这个信息本身，比任何方法论都值钱。

当然，也要说一句：列表里的项目质量参差不齐，有些就是玩票作品，有些已经停更了。但这恰恰是它真实的地方——独立开发本来就是这样，有成功的，有失败的，有持续迭代的，有做一半就放弃的。列表只是如实记录了这些，没有筛选出"成功案例"来误导你。
