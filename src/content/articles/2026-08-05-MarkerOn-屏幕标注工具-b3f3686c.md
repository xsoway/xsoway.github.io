开视频会议、录演示、做教程、远程协作——大多数时候你需要的不是截图后画圈，而是直接在屏幕上画，画完还能继续操作下层应用。

以前试过一堆屏幕标注工具，要么几百 MB 还带个常驻进程，要么标注完就退不出去，要么画两笔卡成 PPT。最近有人在 GitHub 上把一个叫 MarkerOn 的项目放出来了，解决的就是这个事。

**MarkerOn 是一个屏幕标注工具，Rust + Canvas 技术栈，安装包 1.5 MB，支持 10 种绘制工具，全键盘操控，带穿透模式，Windows / macOS 都能用。**

---


**1. 轻量——1.5 MB 的安装包，内存占用极低**
用 Rust + Tauri 写的，没有 Electron 那种几十 MB 起步的负担。系统托盘静默运行，不弹多余窗口，没有后台服务，没有遥测。对"录屏时不想让标注工具本身吃掉资源"的场景来说，这个体积就是核心竞争力。

**2. 全屏覆盖，包括任务栏**
大多数标注工具画不到任务栏区域，MarkerOn 直接覆盖整个屏幕。演示时不需要反复切窗口。

**3. 10 种标注工具，覆盖绝大多数场景**
画笔、荧光笔、激光笔、箭头、矩形、椭圆、直线、橡皮擦、文字、序号。数字键 1-8 切换工具，T 是文字，N 是序号。不用进菜单，键盘直接选。

**4. 穿透模式——标注完不退出，继续操作下层应用**
按 X 切换穿透模式，标注层保持可见，鼠标可以点下层应用。演示时画完一段，不用退出标注，直接继续操作，对观感非常友好。

**5. 全键盘操控，每个操作都有快捷键**
从进入/退出标注到切换工具、调整线宽、撤销/重做，全部有快捷键。Ctrl+Shift+D 进入，Esc 退出，Space 呼出工具栏，Ctrl+滚轮调线宽。不需要鼠标点菜单。

**6. 白板模式 + 保留标注**
可设为默认进入白板，按 W 切换。退出标注后可以选择保留标注内容，下次进入自动恢复。白板模式下 Ctrl+C 可复制为图片，直接粘贴到文档或聊天里。

**7. 工具栏可常驻，也可按 Space 呼出**
设置里可以选工具栏常驻显示，紧凑面板，点「展开」看完整选项。面板内含绘制/穿透模式切换按钮，撤销、复制、切换白板都在里面。

**8. 多种绘制修饰键，画直线、矩形、正圆、箭头**
文档里给了完整的修饰键组合：Alt+拖动画直线，Ctrl+拖动画矩形，Shift+拖动画椭圆，Ctrl+Shift+拖动画箭头。画正方形按住 Ctrl+Alt，画正圆按住 Shift+Alt。用熟了可以画得很精确。

**9. 可配置的元素拖拽、橡皮擦模式、吸附角度**
设置里可以调：元素拖拽（关闭/悬停拖动/按住 Ctrl 拖动）、橡皮擦模式（轨迹擦除或对象擦除）、吸附角度步进（按住 Alt 画直线时的吸附角度间隔）。这些细节让工具更贴近个人使用习惯。

**10. 安装方式灵活**
GitHub Releases 下载安装包，Windows 还有绿色免安装版（_x64_portable.zip），解压即用，配置写在程序目录下，不写系统 AppData。Windows 用户也可以通过 WinGet 安装微软商店版本。

---


安装并启动后，MarkerOn 在系统托盘静默运行，不会弹出窗口。

进入标注模式：
```
Ctrl + Shift + D（macOS 为 Command + Shift + D）
```

数字键切换工具（1-8），按 X 切换穿透模式，按 Esc 退出。

刚上手时按 Space 呼出工具栏，面板里有所有工具和模式切换按钮。

---


MarkerOn 不是那种"功能多到看不懂"的项目，恰恰相反——它把一件事做到了极致：轻量、全键盘、不打扰。对于经常录屏、做演示、线上协作的技术人来说，这种工具属于"装上就回不去了"的类型。

值得一提的限制：目前只支持 Windows 和 macOS，Linux 用户暂时用不了。另外，文档里提到的"白板模式下穿透模式不可用"——这个需要注意，白板模式和穿透模式是互斥的。

项目用的是 Tauri v2 + Vue 3 + Vite + TypeScript + Canvas API，技术栈干净，想二次开发或者提 PR 的门槛也不高。GitHub 上已开源，感兴趣的可以去看源码或者直接下载试试。
