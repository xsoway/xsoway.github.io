## **5 分钟快速上手（真 5 分钟，不搞玄学）**

### **1）安装 OpenCode**

安装非常简单，一行命令解决（Linux/macOS）：

```
curl -fsSL https://opencode.ai/install | bash
```

Windows 用户直接从官网下载安装包就行。

macOS 用户也可以用 Homebrew：

```
brew install opencode
```

安装完验证一下：

```
opencode --version
```

如果报错按提示修就行，基本没什么坑。

- -----

### **2）配置 API Key（让它真的能干活）**

OpenCode 本身是工具壳，它要接上模型才会开始“产出价值”。

最简单的方式是设置环境变量：

#### **✅ OpenAI：**

```
export OPENAI_API_KEY="your-api-key"
```

#### **✅ 或者用智谱 GLM（国产，性价比高）：**

```
export OPENAI_BASE_URL="https://open.bigmodel.cn/api/paas/v4"
export OPENAI_API_KEY="your-zhipu-api-key"
```

或者你嫌配环境变量麻烦，直接用交互式登录：

```
opencode auth login
```

按提示输入 API Key 就行。

OpenCode 可以通过 “Oh My OpenCode” 扩展，让多个 AI 模型并行工作。

你可以这么配：

- GPT-4 负责代码生成

这就进入一种新状态：

> **你不是在用 AI，你是在调度 AI。**

- -----

### **玩法 3：本地模型部署（离线开发，数据不出电脑）**

结合 Ollama，可以实现完全离线开发，隐私直接拉满。

```
# 安装 Ollama
curl -fsSL https://ollama.ai/install | bash

# 拉取模型
ollama pull codellama

# 在 OpenCode 中使用
export OPENAI_API_KEY="ollama"
export OPENAI_BASE_URL="http://localhost:11434"
```

这几行命令的意义非常简单粗暴：

- 你代码不出电脑
- 你数据不进云
- 你网络断了也能继续干活

对于企业开发、敏感项目、或者隐私洁癖来说——

* *这属于一种精神解放。**

## **oh-my-opencode 是什么？（真正的“大杀器”来了）**

简单来说，oh-my-opencode 是一个基于 OpenCode 的“电池全包”AI Agent 框架。

它把各种强大的 AI 模型（Claude、GPT、Gemini）整合在一起，打造出一个核心 Agent：

* *Sisyphus**

你可以把它理解成：

> 一个会分身、会协作、会执行的 AI 团队。

它能像人类团队一样协作，拥有多个专业分身：

- “奥德修斯”（设计、调试）
- “前端工程师”（UI/UX 开发）
- “图书管理员”（文档查找、代码库探索）

并且它不仅是“聊天”，还支持：

- 强大的 LSP（语言服务器协议）工具
- AST（抽象语法树）工具
- 多模型编排
- 并行任务执行

想象一下：

- GPT 负责逻辑推理
- Gemini 负责前端 UI
- Claude 负责文档调研
- 你负责当项目经理发号施令

然后代码就自己长出来了。

## **最佳实践（照做就行，不用理解）**

### **第一步：安装 Bun（必须）**

oh-my-opencode 依赖 Bun 运行时。没它跑不起来。

```
curl -fsSL https://bun.sh/install | bash
```

注意：如果你是 Ubuntu/Debian 并通过 Snap 安装 Bun，可能会遇到 “script not found”，建议使用官方安装器重新安装。

- -----

### **第二步：运行交互式安装器**

```
bunx oh-my-opencode install
```

如果 bunx 不工作，可以使用 npx：

```
npx oh-my-opencode install
```

安装器会引导你完成配置，包括询问你是否拥有 Claude Pro/Max、ChatGPT、Gemini 等订阅。

按真实情况选就行。

- -----

### **第三步：配置认证**

安装完成后，需要配置模型认证。

#### **⬡ Anthropic（Claude）**

运行：

```
opencode auth login
```

选择 Anthropic，按 OAuth 流程完成认证。

- -----

#### **⬡ Google Gemini（推荐）**

推荐安装 opencode-antigravity-auth 插件，实现多账户负载均衡和更多模型支持。

先在 opencode.json 中添加插件：

```
{
  "plugin":[
    "oh-my-opencode",
    "opencode-antigravity-auth@1.2.8"
  ]
}
```

然后运行：

```
opencode auth login
```

选择 Google 并按 OAuth 流程完成认证。

- -----

#### **⬡ GitHub Copilot（备用）**

如果你没有其他订阅，或者想当备用模型：

- 安装时选择启用 Copilot
- 然后运行：

```
opencode auth login
```

选择 GitHub 并完成认证。

## **高效使用技巧：让它像团队一样干活**

### **✅ 1）从 ultrawork / ulw 开始**

不想研究内部机制？最简单有效的方法：

> 提示词里加 ultrawork 或 ulw

Sisyphus 会自动：

- 分析任务结构
- 收集上下文
- 深入挖掘外部代码
- 持续工作直到完成

### **✅ 2）善用专业 Agent**

内置专业 Agent 很多，例如：

- ⬡ @oracle：架构设计、代码审查、策略制定

  示例：

  “Ask @oracle to review this design and propose an architecture”

- ⬡ @librarian：多仓库分析、文档查找、实现示例

  示例：

  “Ask @librarian how this is implemented—why does the behavior keep changing?”

- ⬡ @explore：快速代码库探索、模式匹配

  示例：

  “Ask @explore for the policy on this feature”

- ⬡ @frontend-ui-ux-engineer：前端 UI/UX 开发

- ⬡ @document-writer：技术文档编写

你会第一次感受到：

> AI 不是一个人，它是一支队伍。

- -----

### **✅ 3）后台任务并行处理**

你可以同时让：

- GPT 调试代码
- Claude 找根因
- Gemini 写前端

主 Agent 在任务完成后统一通知你。

这就是“把时间效率打穿”。

### **✅ 4）掌握 LSP 和 AST 工具**

oh-my-opencode 提供强大的工具：

这会让 Agent 能进行精确重构、导航和分析。

让 AI 从“猜测式编程”进化到“工程师式操作”。

- 覆盖 Agent 设置：模型、温度、提示词

- 禁用不需要的 Agent 或功能
- 添加自定义任务类别
