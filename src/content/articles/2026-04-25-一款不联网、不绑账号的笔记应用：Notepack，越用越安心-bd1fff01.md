# 一款不联网、不绑账号的笔记应用：Notepack，越用越安心

- -----

你有没有这种感觉：

只是记个笔记，却要登录、同步、授权一堆东西。

想简单一点，却总被“生态”“云端”“订阅”包围。

如果你只想**安安静静把笔记放在自己电脑里**，那这个项目值得看看。

- -----

## **这个项目是干嘛的（一句话）**

* *Notepack 是一款以隐私为核心、不依赖云服务的桌面笔记与待办事项应用。**

- -----

## **它解决了什么问题？**

Notepack 的出发点非常明确：

> **你的笔记，应该只属于你自己。**

它直接针对几个常见痛点下手：

- 不想把笔记交给云端服务
- 不想被厂商格式“锁死”，以后迁移很痛苦
- 想要一个**简单、干净、快捷**的桌面笔记工具
- 笔记 + TODO，希望都用开放标准保存

Notepack 的选择是：**本地文件 + 开放格式 + 零跟踪**。

- -----

## **核心功能亮点**

- **隐私优先（Privacy by Design）**

  

  - 不联网、不建账号、不做使用统计

  

- **无厂商锁定（No Vendor Lock-in）**

  

  - 所有数据都是普通文件
  - 使用开放格式，随时可迁移

  

- **多工作区管理**

  

  - 一个工作区多个笔记
  - 工作区可设置颜色区分

  

- **TODO 支持标准 iCalendar（VTODO）**

  

  - 不造私有轮子，用通用格式

  

- **快捷键友好**

  

  - 支持纯键盘快速切换笔记

  

- **极简干净的界面**

  

  - 没有多余干扰元素

  

- **多存储后端**

  

  - 本地文件系统
  - WebDav

  

- **支持多种文件格式**

  

  - 纯文本、Markdown
  - PDF、JPG、PNG
  - iCalendar

  

- **笔记加密支持**

  

  - 使用 ZIP AES 算法
  - 笔记以加密压缩包形式保存

  

- -----

## **快速开始**

Notepack 是桌面应用，**无需复杂配置**：

- 支持系统：

  

  - Linux（deb / rpm / AppImage）
  - Windows

  

- 直接从 GitHub Releases 下载即可使用

  👉 https://github.com/Ogefest/Notepack/releases

文档也已经整理在 Wiki 中，结构清晰：

👉 https://github.com/Ogefest/Notepack/wiki/Documentation

- -----

## **关键用法 / 使用方式**

Notepack 的核心使用逻辑很简单：

1. 创建工作区
2. 在工作区中创建或管理多个笔记
3. 笔记直接对应文件系统中的真实文件
4. TODO 使用标准 iCalendar（VTODO）格式
5. 需要时可对单个笔记进行加密保护

不需要学习私有语法，也不用担心“导不出来”。

- -----

## **使用感受（不官方版）**

用 Notepack 的感觉有点像：

> 一个**现代界面 + 老派本地文件哲学**的组合。

它不会试图“留住你”，反而给你一种**随时可以走、但我挺舒服**的安心感。

- -----

## **适合哪些人用？**

- 对隐私非常敏感的用户
- 不想把笔记放进云端的人
- 讨厌厂商格式锁定的技术用户
- 喜欢 Markdown / 纯文本工作流的人
- 想要本地 TODO + 笔记一体方案的人
- Linux / Windows 桌面用户

- -----

## **注意事项 / 小提醒**

- Notepack 是**桌面应用**，不是 Web 服务
- 不提供云同步，需要你自己管理文件或使用 WebDav
- 功能偏克制，追求的是“长期可用”，不是花哨插件生态

- -----

* *如果你想要一款“不打扰你、也不控制你”的本地笔记应用，Notepack 非常值得一试。**
